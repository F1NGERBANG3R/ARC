Important legal distinction
There is no universal document called a “required license” for the entire ARC product. ARC should use:

A proprietary license for SENG THAO-owned application code and original assets.
The original license for every third-party package, model, font, image, or service.
Written commercial-use permission where a third-party license does not clearly allow ARC’s intended use.
Trademark clearance and, where appropriate, trademark applications for ARC, ARC™, Astral Resonance Consciousness, and related marks.
Copyright registration for eligible original works where registration provides meaningful enforcement or procedural benefits.
